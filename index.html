How it opens

Hot corners, gestures and shortcuts

Move the cursor to the top-right corner and drag down - exactly like on Windows 8.x. On a touch screen, swipe from the right edge toward the center.

  • Mouse: top-right corner, then drag down
  • Touch: swipe from the right edge WIP
  • Keyboard: Win + [ temporarily disabled

The charms

Five charms, familiar and faster

Each charm talks to both classic Win32 programs and supported Metro/UWP apps.

Search

Opens the taskbar search on Win32 programs (easily remappable, e.g. to EverythingToolbar) or the Search charm in supported Metro/UWP apps.

Share

Opens the Share charm.

Start

Opens the Start menu. With Open-Shell you can remap it to open that Start menu - or disable the button entirely.

Devices

Opens the Connect charm. In supported Metro/UWP apps it opens the print dialog.

Settings

Opens the Settings app on Win32 programs, or the Settings charm in supported Metro/UWP apps.

New in this fork

Native Mica, built on DWM

The bar is drawn by the Desktop Window Manager itself, so it blends with Windows instead of imitating it.

  • Native DWM window rendering
  • Full support for DWMBlurGlass and OpenGlass
  • Mica by default on Windows 11
  • Fluent UI System Icons

Already included

Everything you loved about the original

Charms Bar Mica is based on Windows 8.1 Update 3 and keeps its behaviour - with a lot more polish.

Format-aware

Uses the OS time and date formats (custom formats are not supported yet).

Language-aware

Switches automatically depending on your OS language.

System accent colours

Picks up the accent colour you chose in Windows.

Network & battery

Status icons for network and battery are included.

Light, dark, contrast

Supports high contrast and light/dark mode preferences.

Fully animated

Emulates Windows 8.x motion - and can be disabled in the OS settings.

Multi-monitor

The bar follows your mouse to the active screen.

Touch-friendly

Built for touch screens - the edge swipe gesture is still in progress.

Win32 ⇄ Metro

Switch modes for the currently focused program.

Win 8.x registry keys

Understands the registry keys of the Windows 8.x era.
