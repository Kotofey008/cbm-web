This is not a stable release. The project is in active development and not meant to be a daily driver for inexperienced users. Download only from GitHub Releases.

Install .NET 7.0

Charms Bar Mica needs the .NET 7.0 runtime. Download it from dotnet.microsoft.com if it is not installed yet.

Download the latest release

Open GitHub Releases and grab the newest build. Extract it anywhere you like if it comes as an archive.

Run the program

Start it and move the cursor to the top-right corner, then drag down, or use the Win + [ shortcut. On touch screens swipe from the right edge (work in progress).

System requirements

  • Windows 11 (recommended) or Windows 10
  • .NET 7.0 runtime
  • Optional: DWMBlurGlass or OpenGlass for the Aero look

Build from source

The code lives in the src folder of the repository and is built with Visual Studio 2022. Pull requests are welcome.
