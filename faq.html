Using it

This requires editing the Windows Registry. I am not responsible for damage caused by incorrect registry modifications.

  1. Press Win + R, type regedit and press Enter.
  2. Navigate to 
    HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\ImmersiveShell
  3. Under ImmersiveShell, create a new key called EdgeUI.
  4. In EdgeUI, create two DWORD values named DisableTRCorner and DisableBRCorner, and set both to 1. Alternatively, create a DWORD named DisableCharmsHint with the value 1.
  5. The hot corners are disabled immediately - no logoff or restart is required.

To revert, set the values back to 0 or delete them.

For a true Windows 10 Technical Preview look, stay on the Windows 8.1 Charms Bar theme and edit the Registry. I am not responsible for damage caused by incorrect registry modifications.

  1. Press Win + R, type regedit and press Enter.
  2. Navigate to 
    HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\ImmersiveShell
  3. Under ImmersiveShell, create a key called EdgeUI.
  4. In EdgeUI, create a DWORD named DisableSettingsCharm and set it to 1.
  5. The Settings panel disappears from the Charms Bar - no logoff or restart is required.

To revert, set the value back to 0 or delete the DWORD.

If you have two or more monitors, moving your mouse to another monitor changes the activeScreen parameter (0 is monitor 1, 1 is monitor 2, and so on), moving the Charms Bar to the corresponding screen.

If it was activated by mouse but has not completely expanded, moving to another monitor forces the Charms Bar to deactivate. This fixes a bug in the original version where the Charms Bar could remain visible on the previous monitor.
